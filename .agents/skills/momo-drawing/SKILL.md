# DRAWING · MOMO’s SKILL 02

把每张图的研究问题、空间证据、视觉层级和可编辑交付连成同一条工作流程。用户本轮指令优先，其次是明确确认的源图和样式、组会文字和对照录音，最后才是已有版式。按地图的表达对象选用参考。行政区名录汇总走名录分布流程，围绕遗址及其地理环境的项目走个案与图册流程。混合任务按各图的表达对象取用。

- [名录分布图](references/roster-distribution.md)｜从名录统计到行政区圆点与色晕，核验交接、统计口径和底稿变体。单幅、区域或全国对照图先用这份流程做地理校核和选样，共用下文的导出检查与版本管理。
- [地图工作流程与地理核验](references/map-workflow.md)｜同步多尺度制图、划定厂区、双时相配准、判断道路和河流。
- [京津冀图式与图册交付](references/atlas-style.md)｜复用蓝色地形、圆形指北针、内嵌或图外图例、横竖版以及原生 AI、PDF 和 PPT。
- [论文组图与机制图](references/research-figures.md)｜用数据组图、流程图或桑基图解释三线研究；也用于本轮明确要求的论文参考风格。

## 个案与图册工作顺序

1. **明确单轮交付。** 盘点用户给出的组会记录、最新微观图、历史影像、GIS 工程、上轮图册和目标期刊。先写明底稿版本、更新哪些场地和尺度、出哪些版式。把会上的意见按宏观、中观、微观逐条归位，记录来源和处理状态，时轴与原音核对状态按实际填写。有歧义且会改写厂号、范围、年代或研究结论时，先推进其他图页，把疑问集中说明；用户明确要求先看计划时，按其顺序推进。
2. **先校地理，再做版式。** 优先用最新版微观原始矢量和已核实影像同步中观；用 QGIS/PyQGIS 或同等 GIS 处理坐标、地形和地理要素，用 Adobe Illustrator 做图层、图式、标注与画板。中国地图的国界、海岸和行政界从可追溯的官方标准地图或有明确来源的 GIS 数据导入。厂址身份、定位精度、现场走访状态和厂区范围分别判断。
3. **先做代表性竖版样页，再扩展。** 用一张典型页和一张困难页检查厂界、地形层次、道路、图例和文字。通过后复用同一主题几何、配色与图例规则生成所需范围和方向。横向展开以地图框和取景重排实现，字保持正向，地图不拉伸；取景一变，重算比例尺并检查外围陆地、海域和标签。

## 导出检查与版本管理

**从导出件反查再交付。** 先检查源数据，再按交付格式重开 AI、独立渲染 PDF、回读 PPT。处理可修复的错位、断线、叠线、重复地名、裁切和叠字后重新验证。证据缺口写入统一待核表，注明影响图页和所需材料。

**控制返工与额度。** 一轮集中处理同类修改，复用中间数据和通过检验的页面。先跑样页和结构检查，批量渲染终版时按受影响的图页或图册重导并复验。长任务记录可续做的版本、已通过检查和待办。额度不可读时按产出批次节制开销，依约定交付。

旧成果按版本保留。默认交付分层原生 AI、分页 PDF、同版 PPT 和一份集中说明；单图或明确指定格式时随任务。说明正文列出图源、证据限制、导出验证及仍需用户提供的资料。每轮按请求选用地图或论文图流程，也可以组合。
