# 三线名录分布图

用于以名录记录为单位的行政区汇总图。开始时写明出哪几幅、统计单位、分类与区域口径、数据版本和视觉底稿。用户若明确指定的是厂址坐标、厂界或双时相遗址图，按个案地理证据表达；同一项目可同时包含这两类图。

## 核对交接与上图记录

1. **确定数据版本和图式版本。** 从交接说明、工作簿和已有交付中分别定位现用名录及用户确认的成稿，核对实际图面和对应台账。继承已确认的纳入口径和图式。收到新版名录时核对作废与现用版本、逐行增删改合和实际计数。将交接图的筛选、视觉变化与用户本轮要求核对。若新版数据会改变点位，而用户指定保留原点位，先完成可独立做的变体，标出受影响的行和待定取舍。复用交接脚本前，检查实际使用的输入、中间文件和导出位置。
2. **判定身份与位置。** 按逐条依据复核疑似重复、同名同号、跨省错挂和大小三线归属。线别依据历史隶属和建设背景，现行政归属用于出图。合并或改类时记录前后值、源行、依据与去向。同名同号的条目先查沿革和隶属，证据不足的补录或定位按待核口径处理。以行政代码或可核对的层级关系匹配市县，记录仅到省级及行政信息冲突的记录。
3. **生成台账。** 每幅图保留源表和行号或原有稳定键、线别、现行政归属与匹配精度、证据档、上图状态、去向或原因。对同一统计范围及去重口径，校验「纳入 = 到所需层级并上图 + 仅省级汇总 + 其他纳入且未上图」及「范围内记录 = 纳入 + 排除」。为每行确定唯一的计数去向，范围未定行另列，并核对合并或改类前后的差额。分组权重之和等于上图记录数，使用圆点时另核圆点数与实际绘制的行政分组数。图注和图例由当轮台账和分组生成。

旧版表格若已有可追溯台账，沿用列与编号。只改样式时复用已核账的数据和分组，比较变体与底稿的坐标、档位及计数。

## 整批换表与逐条补证

- **整批换表。** 先读来源说明、置信度定义和明细表头，按各图所需的行政字段从明细复算记录及地区覆盖。核对分省汇总的分组字段，并确认专题摘录是复表还是独立补充。线别、历史归属、现所在地、坐标含义和档级分别映射。结合本轮交付用途核对表内使用建议与既有纳入口径，记录实际采用的筛选条件。并列两版的新增、缺失和冲突，区分名单差异与覆盖范围变化。图注按实际覆盖注明，省份未定行单列。
- **接续已核证据。** 先用可用的稳定标识，再用厂号、名称沿革、线别和地点交叉匹配，记录新旧两端源行及匹配依据。同名同省只作候选，多对一、迁址和跨线冲突逐项判断。将已经核实的旧证据用于可确认的同一对象。新表字段或档级与旧结论冲突时，在台账保留两端原值、来源和本轮取舍。仅在旧表出现的记录作为差异留痕，其是否补入依据本轮数据范围决定。
- **逐条补证。** 分别判断厂名身份、历史线别、可证行政层级和精确厂址。把改前、改后、采用的证据和各图的处置写入已有台账或变更表。补上县属可提升行政定位精度，归并仍按各图原定尺度。证据有缺口时可从图示退到有依据的汇总层级，身份或线别存疑可暂缓。换名和迁址按时间与地点记录，按本轮统计单位决定如何计数。
- **核对锚点精度。** 含经纬度的记录先看来源和实际含义，市县中心只能支持相应行政层级表达。按实际绘制的行政代码和层级选取代表点，核对其坐标与适用行政范围。缺可核的同级锚点时，保留在有依据的较粗汇总或待核项。

## 汇总、底图和图式

- 全国对照图共享投影、取景、比例尺、地形和适用的数量分级。若使用色晕，两张全国图保持同一平滑与色阶规则。若色晕与圆点并用，两者来自同一份上图分组及权重。行政区汇总圆点用行政区代表点，图注注明统计单位。地区图可选更细的聚合层级和相应的图例。
- 主图和附图均记录底图来源和版本。优先采用可追溯的官方标准地图或行政区矢量，按各层实际坐标系重投影并核对关键轮廓、海域、岛屿和图框。使用官方原图或附图时，明确标注其来源与来源审图号，专题图的审图状态据实另列。
- **《绘制》三图图式实例。** 暖纸底、细行政边界、山地晕渲、区域色晕与分级小圆点。小三线雾蓝、大三线赭褐。京津冀以区县为主，仅定位到市的用空心点。全国以地级行政区为主，按实际情况保留直辖市和省直辖县级单位等例外。组会版采用「可用」「推定」和确认补录，待核单列。当前任务的纳入条件与视觉参数以本轮确认的版本为准。

## 修改底稿与验收

- 按用户确认的成稿做样图，先处理点径、描边、底色、地形或标注等本轮点名的图层。取一幅能看清密集区、色晕和图例关系的图核对，再把同一变更扩展到要求的幅面。保留旧版本及其数据和视觉依据，给另出的小圆点版等变体独立命名。点径或描边变化时同步更新图例，核对源分组和符号锚点。
- 补证或换表后，按各图的行政代码和层级逐组比较增减、权重、档位与锚点，并比对图注、图例和共享参数。总数相同也要核组别。只补依据且图面无变化时更新核验记录即可。局部变化重绘受影响的图与图层，复用参数和内容均一致的已验收单页，在独立输出目录重组交付。
- 复核全国对照图的共同图幅、分档和尺度，检查逐行台账与图上计数。临时替换或新增的数据需经本轮核账。导出后逐图检查地形、边界、圆点层、色晕、图例、附图与文字的遮挡关系，并按主技能核对各格式的页序和可编辑项。
- 对直接复用的单页核对来源文件或哈希。若要求沿用官方附图，可比对嵌入图源或在一致渲染条件下比对附图范围。重新合订后逐页核对与当轮单页的内容、顺序及更新处。
- 需要移机或续跑时，在现有交接说明中登记工作簿、母版和底图版本，列可解析的输入位置、重导页、复用文件、依赖、运行入口及已通过的核验。重跑前确认输入齐备，按当轮台账计算预期值。
