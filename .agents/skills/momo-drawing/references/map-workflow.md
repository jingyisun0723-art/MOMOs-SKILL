# 地图工作流程与地理核验

## 取材与证据

- 建一张制图台账，至少记录对象 ID、标准名称与别名、历史身份及隶属的出处、现行政属、走访状态、坐标及其来源和精度、两期边界依据、在各图册的展示状态。历史隶属与现行政属分栏；现场到过区域、精确厂址和历史身份是三项独立信息。区域示意、截图拟合、共用坐标和待认定对象均保留原精度。数量按本轮确认的清单去重并复算。
- 组会资料优先读教师明确修改意见和带时轴的讨论段。录音中的「这里」「这条路」需结合指图截图或矢量；自动转写有厂号、地名、年代歧义时核对原音与其他材料。用一张对照表记录 `要求｜所属尺度与对象｜证据或时间码｜处理｜验收结果｜待补材料`。
- 优先复用可打开的 QGIS 工程、GeoPackage、带地理坐标的建筑矢量与原始影像。只有 PDF/SVG 时检查是否为矢量，保留图框、比例尺和变换；只有图片时用稳定可识别的道路转折、山谷、桥或可靠建筑选多处分布均匀的控制点，并用未参与拟合的点交叉检查。配准记录投影、影像时相、重叠范围、独立检查结果和误差可接受的图示尺度。影像倾斜和地形位移可能使局部对齐、远处错位。
- 中国国界、行政界、海岸线和海域标注用可追溯图源及其规定表达；需要国界、省界或公开发表时查现行官方标准地图、目标刊物和适用标注要求，从所选图源记录版本、出处及适用时的审图号。局部路水、聚落、DEM 可来自不同数据源，逐层记来源、时相、坐标系和用途。叠图前统一 CRS 并核查轴序、地图服务偏移、制图尺寸和米/千米换算。
- 优先并排比对最新版微观图、现状底图、年代明确的历史影像和现场资料。保留共享源几何和编辑后的展示几何，以便追查变更。局部确认以共享几何同步至上一级，外围底图另补；资料矛盾处保留待核记录和截图。

## 三个尺度如何协同

| 尺度 | 问题 | 表达与核验 |
| --- | --- | --- |
| 宏观 | 调研对象在省域、山地和城镇体系中怎样分布？ | 按对象 ID 与坐标清单检查漏点、同址或估位、重复名和引线对应。突出调研点与主要行政界，补必要海域和城市。文章精选版和含待核对象的研究底图按用途另存，统计口径由当前台账生成。 |
| 中观 | 厂区如何与山谷、道路、水系、周边村落相连？ | 沿有依据的外缘概括厂区，村落表达可见建成块面和名称，主要道路、水系、桥隧与厂区入口相互对照。原范围展示厂区细节；扩大范围交代厂村、厂群与交通关系。逐栋建筑及功能编码留给微观。 |
| 微观 | 厂区内部建筑如何分布、使用和变化？ | 按场地资料区分现存、拆除、年代未定，以及已证实的生产、办公、生活等功能。沿用户认可的最新版图式表达；核对原图的逐栋身份、相邻建筑、位置、功能文字及实拍图引线。 |

### 厂界与历史对照

1. 从微观图中分别提取有依据的现状厂属建筑和历史建筑层。分期独立勾勒轮廓再叠合。现状外围贴建筑或已证实的用地外缘，连续建筑群优先概括为一个闭合面，实地有河道、泄洪通道或明确道路造成分隔时保留分块。周边民居、宿舍和远端配套先核归属。色块和轮廓在资料不足时表述为研究判读范围。
2. 历史厂区边界、历史聚落和历史交通各有独立证据和图层。调研问题确实要求且材料可证时，核对现状是否落在历史范围内；发现越界先查配准、两期取样、拆建或真实扩张，有证据再调整。合图沿用单页同源几何和实际坐标。
3. 道路检查主路到厂入口的路线、道路等级、路口、跨河桥、铁路和穿山段。把无连接的小间隙、同源异版本叠线、道路跨越而不相交分别核实。连接须有路口或历史线迹证据；历史影像掩蔽处保留可辨终点。只保留与图意有关且能识别的支路。行政等级以有依据的编号和来源核实。
4. 区分水面、河流或沟渠中心线、可辨河岸或裸露河床、泄洪区。河宽用可定位的河岸或具明确时相的影像量测。检查历史道路是否被沟渠阴影、田埂或现代轨迹误识别。两期线面不因视觉需要强行重合。

## 地理验收

- 检查无效/空几何、闭合、错位、重复或自交；同一区域的填色与边界用同一几何生成。核实松散端点、断头、交叉、桥隧和铁路叠线的实际原因，保留真实终点和有意义的分隔。
- 比对缩放前后或单页与合图的共同对象和原坐标。对宏观完整陆地范围检查 DEM 的 NoData、行政裁切与图幅新增区；对中观叠查厂界覆盖、道路水系、标注引线和图例样式。记录检查覆盖范围；区分几何结构检查、影像叠核和实地确认。
- 证据不足时记录对象、具体要素或段落、来源缺口、图上处理、需要补的材料。对于新线索、疑似点位或缺失图层，工作数据有出处可回查，最终表达与证据匹配。
